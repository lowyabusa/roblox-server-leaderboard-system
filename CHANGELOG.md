# Changelog

## v0.2.0

- Add explicit daily and weekly leaderboard periods.
- Add `LeaderboardService.SetPlayerPeriodValue`.
- Add `LeaderboardPeriod` display board support.
- Generate configured period boards from the Command Bar setup script.
- Document UTC reset behavior and period-owned server values.

## v0.1.0

- Initial public release.
- Includes server-authoritative leaderboard publishing through
  `LeaderboardService.SetPlayerValue`.
- Includes `OrderedDataStore` ranking reads and writes.
- Includes generated Workspace display boards under `Workspace.Leaderboards`.
- Includes a Roblox Studio Command Bar setup script and server-only example
  publisher.
